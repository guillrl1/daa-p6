# DAA · Práctica 6

Diseño y Análisis de Algoritmos · Universidad de La Laguna · Grado en Ingeniería Informática.

Implementación en C++ de dos algoritmos para el problema de máxima diversidad sobre conjuntos de puntos (instancias `examples/max_div_<n>_<k>.txt`):

- Algoritmo constructivo voraz (`greedy_solver`)
- Ramificación y poda (`bb_solver`)

## Estructura

- `include/` y `src/`: instancia, puntos y solvers
- `examples/`: instancias de prueba
- `Makefile`: compilación

## Compilación

```bash
make
```
